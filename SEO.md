# Configuración SEO

## URLs indexables

- `https://kcmasajesybelleza.es/`

La web es actualmente una landing estática. No se deben crear páginas de servicio hasta disponer de contenido real y diferenciado para cada tratamiento.

## Google Search Console

1. Crear una propiedad de dominio para `kcmasajesybelleza.es`.
2. Verificarla mediante el registro DNS que proporcione Google.
3. Enviar `https://kcmasajesybelleza.es/sitemap.xml`.
4. Solicitar la indexación de la portada tras cada cambio sustancial de contenido.

No se ha añadido ninguna etiqueta de verificación ficticia.

## Google Analytics 4

Cuando exista un ID real `G-XXXXXXXXXX`, insertar el script oficial inmediatamente antes de `</head>` en `index.html`. Antes de activarlo, revisar si el uso previsto requiere un sistema de consentimiento de cookies.
